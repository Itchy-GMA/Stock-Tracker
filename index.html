セットアップガイド

  1. このリポジトリを Fork またはそのまま使う
  2. stooq apikey を無料取得（登録不要・CAPTCHAのみ）
  3. GitHubリポジトリの Settings → Secrets → Actions で STOOQ_APIKEY を追加
  4. Settings → Pages で main ブランチの /（root）を公開設定
  5. 下の「銘柄を追加」から証券コードを入力 → results.json に保存
  6. 毎週土曜13:00に GitHub Actions が自動実行・株価更新
